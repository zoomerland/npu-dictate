# NPU Dictate: локальная русская диктовка на Intel NPU

Сделал небольшое Windows-приложение: нажимаешь кнопку или горячую клавишу, говоришь, текст вставляется в выбранное поле. Можно удерживать кнопку или включать и останавливать запись двумя нажатиями. Есть пунктуация, трей и необязательная отправка Enter после вставки.

Главная причина проекта: попробовать использовать Intel NPU для повседневной диктовки, а не только для демо. Сейчас распознавание русской речи работает через GigaAM v3 CTC / OpenVINO NNCF INT8, пунктуация отдельно через RUPunct_big. Проверено на Intel Core Ultra 5 135U / Intel AI Boost с Windows 11 и OpenVINO 2026.2.0. Есть отдельный CPU-профиль. На GPU и NVIDIA работу не проверяли; захват звука, VAD и обвязка остаются на CPU.

Модели скачиваются при первоначальной подготовке, после этого обычная диктовка локальная. Первая компиляция для NPU может быть долгой. Сейчас это alpha, EXE и MSI ещё без цифровой подписи. Интерфейс русский/английский, но распознавание пока только русское.

Нужны тесты на других Intel NPU, сообщения об ошибках и предложения по коду. Особенно интересны первый запуск, длинная диктовка и вставка в разные приложения. Не прошу отправлять личные записи: для воспроизведения лучше несекретная тестовая фраза и диагностика с удалёнными личными данными.
