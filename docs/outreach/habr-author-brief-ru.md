# Фактура для авторской статьи на Хабре

Это рабочая справка, не готовая статья для публикации. Проверенные на 2026-10-03 [правила Хабра](https://habr.com/ru/docs/help/rules/) запрещают полностью или частично сгенерированные и отредактированные ИИ тексты, кроме небольших дополнений к большой оригинальной технической авторской статье. Старый сгенерированный черновик нельзя выдавать за такую статью. Автору нужно написать собственный текст; автоматическую публикацию не выполнять.

Отдельно нужно учитывать ограничения самопиара: авторский текст сам по себе не разрешает рекламную публикацию. Техническая статья должна быть полезна независимо от ссылки на приложение; спорный формат лучше заранее согласовать с редакцией.

## Первая Часть: Для Пользователя

- Название: NPU Dictate. Задача: локальная голосовая диктовка в поля Windows-приложений, горячая клавиша/плавающая кнопка.
- Целевая платформа: Intel NPU; проверенный ноутбук Core Ultra 5 135U / Intel AI Boost. CPU-профиль доступен отдельно. NVIDIA/GPU не проверены.
- Только русская речь, несмотря на русский и английский интерфейс.
- Первый запуск требует моделей и может долго компилировать NPU-кэш. После подготовки обычная диктовка не требует сети.
- Статус: unsigned alpha.5, не обещать стабильность или отсутствие предупреждений Windows.
- Что попросить у читателя: тест другого ноутбука, понятное воспроизведение бага, предложения по интерфейсу, PR. Личные записи не нужны.

## Вторая Часть: Для Разработчика

- Две модели, ASR и пунктуация, с отдельными профилями устройств. Не весь конвейер работает на NPU.
- GigaAM v3 CTC: CPU ONNX INT8 и NPU OpenVINO NNCF INT8 b400. Реальная длина передаётся отдельно от статического входа.
- VAD, независимые сегменты, склейка в приложении. Это не потоковая модель с памятью между вызовами.
- RUPunct_big FP16 static128: длинный текст в перекрывающихся окнах, вывод по исходным словам без абзацев на границах окон.
- Вставка через Windows/UI Automation, буфер и клавиатурные события; при небезопасной смене цели автоматическая вставка прекращается.
- Холодная компиляция и тёплый запуск различаются. Цифры README исторические, для ASR, не WER и не оценка батареи.
- Честные оставшиеся ограничения: повторы слов, незнакомые редакторы, один проверенный тип NPU, unsigned сборки.
