## Предварительная классификация

### Уникально для `features/next`

- Очистка начальной пунктуации применяется без учёта контекста поля и может удалить смысловой знак при продолжении существующего текста.
- Очистка всех Unicode-знаков пунктуации может оставить непарную закрывающую скобку или кавычку.
- Автоматический `Enter` после вставки не подтверждает, что фокус остался в том же целевом окне.
- Ошибка отправки `Enter` не отражается пользователю отдельным статусом.

### Уже присутствует в `main` (подтверждено P0)

- Окно гонки между остановкой записи и установкой состояния транскрибации.
- Публикация устаревшей ASR/пунктуационной модели после изменения настроек во время загрузки.
- Неатомарная запись JSON-конфигурации и отсутствие восстановления после повреждённого JSON.
- Возможность принять недокачанный direct-download файл без ожидаемого размера/хеша.
- Потеря последней диктовки при выходе во время остановки/транскрибации.
- Гонка при параллельном создании аудиопотока.
- Ошибки микрофона/PortAudio могут сорвать запуск до появления интерфейса.
- Неочевидное завершение при ошибке single-instance mutex.
- Смешение каталога ресурсов приложения и пользовательских изменяемых данных.

## Контрольные условия

- В feature-fix не входят общие старые дефекты или архитектурные рефакторинги.
- Перед каждым слиянием рабочее дерево чистое, проверки записаны ниже, а diff соответствует цели ветки.
- Общие исправления делаются отдельными тематическими коммитами с регрессионными тестами.
- Личные аудиозаписи, модели, кэши и собранные бинарные артефакты в Git не добавляются.
- При обнаружении неожиданного изменения пользователя работа останавливается до безопасного уточнения области.
